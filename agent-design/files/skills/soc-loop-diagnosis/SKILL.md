# SOC 循环诊断

## 诊断框架

SOC 的核心不是“内容多”，而是**玩家在持续压力下，把环境转化为可积累的安全与能力**。围绕这句话检查五条链。

### 链 1：生存链

- 压力是否持续存在，还是前期有、后期消失？
- 压力来自环境、资源、其他玩家，还是三者组合？
- 玩家能否通过成长把压力转化为可控风险？
- 压力消失后，有没有新的压力源接替？

### 链 2：生产链

- `采集 → 转化 → 建造/制造 → 更强采集` 是否闭环？
- 中间产物有没有被共享，还是每条生产线各造一套？
- 生产设施的工序关系是否清晰（工序 vs 分类）？
- 产出有没有被系统或玩家消费？

### 链 3：成长链

- 成长是否同时带来“能力提升”和“新决策”？
- 是否存在纯数值成长（只变强，不改变玩法）？
- 后期有没有新的目标类型，而不只是更高的数值门槛？

### 链 4：风险/对抗链

- 产能是否等于风险阀门？（产量越高越容易被盯上）
- 掠夺是零和、负和还是正和？
- 被掠夺方有没有恢复机制与安全期？
- 高端战斗的成本是否把玩家劝退？
- 后期大型对抗有没有除名次以外的奖励？

### 链 5：时间链

- 进度有没有周期性封档（赛季、剧本、wipe）？
- 没有封档时，先发优势是否持续复利？
- 冷服/低活跃时，节奏是否还能成立？
- 内容消耗速度与产出速度是否匹配？

## 关键结构判定

### 局容器三件套

如果游戏涉及 PvP、撤离、周期对抗，检查是否具备：

| 要素 | 作用 | 缺失后果 |
| --- | --- | --- |
| 结算点 | 局内所得在出局时折算 | 货币与战斗脱钩 |
| 局外安全期 | 打完之后有地方恢复 | 受害者纯负和挫败 |
| 进局动作 | “入场”让名次和风险有意义 | 后期名次空转 |

**无边界大世界 = 登录即在地图，没有入局也没有出局**。此时上面三样无处安放，相关断点不是调数值能解决的。

### 时间层与身份层

多人对抗要长期成立，需要两层：

| 层 | 作用 | 缺失后果 |
| --- | --- | --- |
| 时间层 | 赛季/剧本/wipe，给进度设闸 | 强者恒强，只能开新服 |
| 身份层 | 专精、职业、武器主修等分工 | 弱者找不到位置，GVG 退化为纯数值 |

两层是**相乘**关系：只缺一层还能靠另一层缓解；两层都缺，新人既没有立足点也没有翻身窗口。

## 输出结构

```markdown
## 结论
（循环成立 / 某条链断裂 / 结构缺失，一句话）

## 五链诊断
| 链 | 状态 | 证据 | 断点 |
|---|---|---|---|

## 结构判定
（局容器三件套 / 时间层 / 身份层，逐项）

## 结构问题 vs 数值问题
（明确分类；结构问题不要给调数值方案）

## 干预方案
（至少两个方案：保守 / 重构；各自代价与副作用）

## 最小验证
（一个可验证的假设 + 验证方法）
```

## 常用诊断结论

- **管子非循环**：有投入有产出，但产出不回流，玩家状态不变。
- **货币脱钩**：战斗只掉物品和经验，没有可回收的货币/结算点。
- **零和无补偿**：被掠夺方损失无法恢复，且没有安全期。
- **名次空转**：大型对抗只有排名，没有实质奖励或进局成本。
- **冷服死寂**：节奏依赖其他玩家的活跃度，没有内生节奏源。
- **两端混搭**：策略端的复杂度 + 挂机端的离线生产，两边的爽点互相抵消。

## 质量门槛

- 先判断结构，再谈数值。
- 每个断点必须有证据或明确标为推断。
- 干预方案必须写副作用，不能只写收益。
- 不把“加内容”当成循环修复方案。
- 涉密底座的内容只在本地使用。
