# 顾问知识库 · 索引（沙盒生存策划顾问）

> 这套知识库是一把"沙盒生存游戏设计尺子"，给 persona 和任何读它的人用。
> 7 篇方法论：全是**可迁移内核**；项目事实只在浅案例里当佐证，**不当标准**。

---

## 怎么用（顺序固定，先答再查）

1. **先答灵魂问题**：这套系统是给"想动脑的策略玩家"，还是"想省心的挂机玩家"？两端爽点相反，别混做。
2. **再做定位三问**：它改变玩家哪种状态 / 制造什么决策 / 产出去了哪成环了吗。
3. **用四死法诊断**：管子非循环 / 僵尸系统 / 操作粒度泄漏 / 误建模。
4. **按题材查对应手册** ↓

## 7 篇一览

| 题材 | 手册 | 一句话内核 | 一句红线 |
|---|---|---|---|
| 基地 / 家园 | 《家园系统方法论》 | 家园=成长循环载体，非仓库；生产六法则；双轨成长轴 | 放大器必配消耗链 + 风险阀门 |
| 可造平台 | 《载具平台系统方法论》 | 平台=能力放大器 + 依赖链四漏勺；双轨成长轴 | 冲突惩罚留抢救口，只爆部件不爆整机 |
| 经济循环 | 《玩法循环方法论》 | 产能=风险阀门 + 零和掠夺 + 正和养成回收三角 | 创新只许动操作层 / 节奏层 |
| 生存数值 | 《生存属性系统方法论》 | 属性三层骨架 + 互转兑换表 + 服务器权威 | 认准配置载体，别认编号 |
| 原料入口 | 《采集链路方法论》 | 先定操作粒度；采集三要素 | 采集必须 O(1) 批量，刷新 / 去向别封黑盒 |
| 战斗 | 《射击战斗方法论》 | 手感词条化 + 部位万分比 + 耗材净支出 | 手感用词条、结算在服务端 |
| 交互 | 《交互易用性方法论》 | 优化即减摩；四维判据 | 先减认知摩擦，减摩不增负 |

## 跨系统总红线（七篇共用）

**凡要"配置化"的 → 留表；凡要"改手感 / 节奏"的 → 用参数曲线；凡要"起冲突"的 → 给惩罚留抢救口；凡是"放大器 / 产能"的 → 必配一条"消耗链 + 风险阀门"。**
