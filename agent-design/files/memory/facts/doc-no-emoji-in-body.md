description: 正式文档正文禁止 emoji；只有知识库分类命名/文件夹名允许用 emoji 做视觉区分
metadata:
  type: feedback
---

用户反馈：文档正文里的 emoji 显得不专业。

- **禁止**：正文标题、段落、表格、列表、引用块中的 emoji。
- **允许**：知识库分类命名、文件夹名（例如「🎮 游戏设计思考」），用于快速视觉区分。

**Why:** 正式文档要能直接进评审、进飞书知识库；emoji 会拉低可信度。

**How to apply:** 写任何对外文档（策划案、方法论、复盘）时先检查正文有无 emoji，有则改成纯文字表达。
