# 玩法循环 · 方法论手册（沙盒生存通用）

> 适用：任何求生 / 建造 / 射击 / 经营，甚至 SLG 类游戏的经济循环设计。
> 纯方法论 + 浅案例。仅作设计原理参考，**不是任一游戏的标准**。

---

## 0. 一句话定位

求生 / 建造 / 射击 / 经营，甚至 SLG，内芯都是同一副经济骨架：**生产建造是正和养成，掠夺对抗是零和转移，两者用"风险阀门"耦合。** 循环断了一条链，张力和成长感就同时泄气。

---

## 1. 通用骨架三角（可反复验证的公式）

- **产能 = 风险阀门**：生产设施产能越高，越容易被瞄准，产量本身即掠夺目标。总开关要显式、可调。
- **零和掠夺**：攻打方所得 ≈ 守方所失，且负和转移（有结算损耗）。
- **正和养成回收**：采集 → 制作 → 打怪掉资源回流；击杀 → 建造打通。系统回收净化部分物资，防无限转手"秃鹫"。

---

## 2. 断链诊断（三角缺一角就出问题）

| 缺的角 | 症状 |
|---|---|
| 只有正和养成，无掠夺 | 无张力的单机，产能 = 白嫖 |
| 只有零和掠夺，无正和回收 | 纯 PvP 内卷，成长感缺失 |
| 产能不挂风险阀门 | 高产出无风险，负反馈断裂 |

---

## 3. 与 SLG 的共通（预研价值）

两类游戏共享同一副经济内核，差异只在对抗的**操作层与节奏层**（SLG 数值战 / 赛季切图 vs 写实射击 FPS 手感）。这证明"风险阀门 + 掠夺 + 养成"是有成熟品类背书的一般规律，不是本作自创。

---

## 4. 边界形态（决定"局"的形态）

多数 SLG 用**赛季 / 地图切换**（形态① 有边界）；实时生存常态**实时切战斗状态**（形态② 无边界）。边界有无，决定了"局内资源池 / 结算回收 / 是否单局"这组设计。

---

## 5. 决策检查清单（上线前自检）

- [ ] 三角健全吗——产能挂风险阀门？有无零和转移？正和回收闭环了吗？
- [ ] 产能越高是否越是别人的目标？（而非越高越安全）
- [ ] 系统回收能防"无限转手的秃鹫"吗？
- [ ] 边界形态定了吗——赛季切图（有界）还是实时切状态（无界）？
- [ ] 差异是落在操作层 / 节奏层，还是误动到了经济内核？

---

## 6. 附：一条可复用红线

**经济内核（风险阀门 + 掠夺 + 回收）三脚必须俱全；创新只许动"对抗的操作层 / 节奏层"，不许动内核。** 动内核 = 拿爆款验证过的骨架冒险。

---

## 7. 附：可迁移的"设计陷阱"原型（浅案例）

- **无限转手秃鹫**：一个物件没被系统回收，就在玩家间无限转手套利，通胀并抽干产出价值。→ 教训：给系统加"回收 / 净化"出口。
- **无边界实时切换 vs 赛季制**：无界 = 随时被追，资源是浮财；有界 = 整局经营，资源是筹码。两种边界导向完全不同的"局"设计。
