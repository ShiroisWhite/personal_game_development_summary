# 载具 / 可移动平台系统 · 方法论手册（沙盒生存通用）

> 适用：任何"玩家用资源造出来、用来放大能力、同时制造依赖链"的系统——载具 / 坐骑 / 飞机 / 机甲 / 船只 / 甚至家国经济平台。
> 与《家园系统方法论》共用同一套纯方法论 + 浅案例骨架。仅作设计原理参考，**不是任一游戏的标准**。

---

## 0. 一句话定位

"平台系统"不是交通工具，而是玩家**用资源造出来的能力放大器**，同时它主动制造一条**依赖链**（燃料 / 修理 / 部件 / 弹药），把玩家不断推回采集-制造主循环，并成为 PvP 的**掠夺对象**。

它可承担的角色（**选 1 个主锚 + 最多 2 个次锚**）：
- **机动平台**（跑图 / 开图）
- **火力平台**（输出）
- **载量平台**（储物 / 运货）
- **持久平台**（续航 / 生存）

---

## 1. 设计定位三问（先回答，再动手）

一个"平台系统"必须回答三个问题：

1. **它放大什么能力？** 机动 / 火力 / 载量 / 持久 —— 选 1 主锚 + 最多 2 次锚。
2. **它的消耗如何回流主循环？** 必须规划至少 1 条"持续消耗 → 回流生产"的链。**没有消耗的平台 = 玩家永不回生产环 = 产能塌方。**
3. **它是否成为冲突 / 掠夺对象？** 有 PvP 时，平台应成为"风险阀门"（能造出能力，也能被抢 / 被打掉）。这决定了"死亡是掉血还是掉物"。

---

## 2. 六层骨架（任何平台系统通用）

```
数据层(品类/属性/数值) → 世界层(实体/物理/同步)
→ 手感层(曲线/相机/操控) → 经济层(漏勺回流)
→ 冲突层(攻击/防御/掠夺) → 入口层(UI/轮盘/交互)
```

每层都要"配置化"：数据在表、世界在引擎、其余在逻辑热更层——**改玩法只动配置 + 逻辑，不动引擎。**

---

## 3. 四条消耗漏斗（最容易被漏掉的一层）

| 漏斗 | 频率 | 回流机制 |
|---|---|---|
| 燃料 | 持续(按秒) | 采集 / 购买 |
| 耐久 / 修理 | 受击才掉 | 材料(配方) |
| 部件 / 改装 | 一次投入 + 死亡掉 | 加工 + 掠夺 |
| 弹药 | 战斗 | 采集 / 补给 |

> 检查你自己的平台系统：**这四条有一半没有 → "吃资源不出资源"的死系统；四条全有 → 把玩家焊死在生产环 —— 活系统。**

---

## 4. 双轨成长轴（防归零）

一条 **平台等级轴**（换更强平台）+ 一条 **部件等级轴**（堆升级件）并行。

- 不会"换新 = 旧全废"的挫败（件可迁移到同品类）；
- 不会"一代吃遍天"的平淡（平台有硬瓶颈，不堆件到不了上限）。

> 只有一条成长轴 = 要么挫败，要么平淡。

---

## 5. 放大器 + 风险阀门（跷跷板）

- **放大器面**（正和：造出能力）→ 让玩家变强、推进度；
- **风险阀门面**（零和 / 负和：能被抢 / 被打掉）→ 让玩家为保住它而投入。

**放大器太强 → 碾压；风险阀门太强 → 没人敢造。** 校准 = 输出要够爽（放大器），但消耗 / 掉件也在（阀门）。

> 死亡惩罚要"克制的失去"——**只爆"部件"，不爆"整机"**，给"抢救"留口子。否则一次清空 = 永久劝退。

---

## 6. 决策检查清单（上线前自检）

- [ ] 它放大什么能力？主锚 + 次锚选定了吗？
- [ ] 四漏勺齐全且有回收环吗？(燃料 / 耐久 / 部件 / 弹药)
- [ ] 它是纯消耗还是能放大能力？（纯消耗 = 死系统）
- [ ] 死亡惩罚给"抢救"留口子了吗？(可弃可救，而非纯删)
- [ ] PvP 下它成为掠夺对象了吗？掉落克制吗（不爆整机）？
- [ ] 是单轨还是双轨成长？防归零了吗？
- [ ] 每一类平台的"能力主张 + 手感"有区别吗？(还是只差皮)
- [ ] 长期不用的平台回收了吗？(防挂服务器 / 防灾控)
- [ ] 服务器权威吗？(数值 / 碰撞 / 掉落在服务端)，客户端只做表现

---

## 附：一条可复用红线

**凡要"配置化"的 → 留 Excel；凡要"改手感"的 → 用曲线而非写死数字；凡要"起冲突"的 → 给惩罚留"抢救口"；凡是"放大器" → 必配一条"吃它的消耗链 + 风险阀门"。**

> 这条红线适用于本作所有"玩家可造、能放大能力、又怕被抢"的系统（载具 / 家园 / 公会 / 生产线）。

---

## 附：可迁移的"设计陷阱"原型（浅案例）

抽象成模式的坑，举一反三用：

- **"会动的炮塔" vs "会跑的箱子"**（定位之争）——坦克不是载具的加长版，它有独属的"能力主张 + 手感"。教训：**同类平台的区别要落在能力 + 手感，不是只换皮。**
- **空车架 vs 满配件**（成长轴）——一条轴靠"换更强的"，一条轴靠"堆更好的件"，并行防归零。
- **爆整机 vs 爆部件**（惩罚口）——死亡惩罚克制掉"部件"给玩家留抢救口，否则没人敢造。
