# 失败模式库

每条包含：症状、根因、验证方法、修复方向。诊断时逐条判断“命中 / 不命中 / 不适用”。

## 1. 管子非循环

- **症状**：玩家持续投入，产出进入仓库后不再影响任何状态。
- **根因**：产出没有消费方或回流路径。
- **验证**：追踪一条产出，问“谁消费它？消费后改变了什么？”
- **修复**：增加消费方、把产出转为能力、让产出成为下一轮投入。

## 2. 僵尸系统

- **症状**：新系统上线后，旧系统仍存在、仍占资源、仍出现在 UI，但不再产出价值。
- **根因**：没有生命周期管理；被上位替代后没有退场或转型。
- **验证**：加入新内容后，旧系统的使用率与产出价值是否归零？
- **修复**：退场、合并、转型为其他生态位，或明确保留理由。

## 3. 操作粒度泄漏

- **症状**：玩家需要逐棵树、逐块田、逐个箱子地操作；规模越大越痛苦。
- **根因**：技术实现的最小单元泄漏成了玩家操作的最小单元。
- **验证**：操作成本是 O(1) 还是 O(N×k)？
- **修复**：批量选择、区域操作、自动化流转、蓝图/模板。

## 4. 两端爽点混搭

- **症状**：系统既有策略端的复杂度，又有挂机端的离线生产；两边玩家都不爽。
- **根因**：没有先选择目标玩家。
- **验证**：目标玩家是想动脑还是想省心？系统是否同时要求两者？
- **修复**：选一端为底，另一端作为可选深度；不要强迫所有人走同一条路。

## 5. 品类缝合失败

- **症状**：同时融合 SOC + MMO + SLG + PvP，但每个品类的核心结构都没成立。
- **根因**：缺时间层（赛季）与身份层（RPG 分工），导致强者恒强、团队退化为纯数值。
- **验证**：进度有没有周期封档？玩家有没有可选择的专精身份？
- **修复**：先补两层结构，再谈品类融合；不要用更多系统掩盖结构缺失。

## 6. 货币脱钩

- **症状**：战斗只掉物品和经验，没有货币/结算点；对抗是纯消耗。
- **根因**：缺少局内结算点或战斗产出的回收路径。
- **验证**：打一场的净收益是否长期 ≤ 0？
- **修复**：增加结算点、可回收产出、PvP 实质奖励。

## 7. 零和负和

- **症状**：被掠夺方损失无法恢复，且没有安全期；受害者持续流失。
- **根因**：掠夺是零和/负和，缺少补偿与恢复。
- **验证**：守方损失后能否在合理时间内恢复？离线是否被保护？
- **修复**：安全期、保护比例、恢复机制、正和来源。

## 8. 后期名次空转

- **症状**：大型对抗只有排名，没有实质奖励或进局成本。
- **根因**：缺少“局”容器与结算。
- **验证**：参加与不参加，玩家收益差多少？
- **修复**：进局成本、结算奖励、赛季封档、名次对应的实质内容。

## 9. 冷服死寂

- **症状**：服务器活跃度下降后，掠夺无目标、交易无市场、对抗凑不齐人。
- **根因**：节奏完全依赖玩家活跃度（内生驱动）。
- **验证**：人数减半后，核心循环是否还成立？
- **修复**：PvE/环境事件、NPC、异步目标、降低实时人数依赖。

## 10. 通胀与稀缺并存

- **症状**：低阶资源过剩、高阶资源被少数人垄断；经济两极分化。
- **根因**：产出与回收不匹配；高端产出被少数效率玩法垄断。
- **验证**：资源存量分布、价格曲线、回收率。
- **修复**：分层回收、动态产出、高端资源的替代路径。

## 11. 内容消耗快于产出

- **症状**：玩家几天内打完所有内容，之后无事可做。
- **根因**：内容驱动而非系统驱动；更新速度跟不上消耗。
- **验证**：玩家从进入到“无事可做”的时间。
- **修复**：系统驱动（组合、目标、社交）、赛季重置、UGC/沙盒。

## 12. 过度参数化

- **症状**：配置表字段爆炸，每个特例都加一个字段；策划难以维护。
- **根因**：用配置表达代码逻辑；没有抽象。
- **验证**：新增一个类似内容，需要改几张表、加几个字段？
- **修复**：抽象规则、用组合替代特例、把逻辑收回代码。

## 13. 数值成长替代玩法成长

- **症状**：后期只是更高的数值门槛，玩家没有新决策。
- **根因**：成长只有纵向，没有横向。
- **验证**：满级玩家和中期玩家的玩法差异是什么？
- **修复**：横向专精、新目标类型、新风险、新空间。

## 14. 压力消失

- **症状**：前期紧张，后期资源充足后没有任何压力。
- **根因**：压力源单一且可被永久解决。
- **验证**：后期玩家还在管理什么风险？
- **修复**：新压力源、维护成本、动态事件、PvP、赛季重置。

## 15. 反馈缺失

- **症状**：玩家做了操作，但不知道发生了什么、为什么。
- **根因**：状态变化没有可见反馈。
- **验证**：玩家能否在 3 秒内说出“刚才发生了什么”？
- **修复**：即时反馈、数值飘字、状态提示、音效/动效。

## 16. 安全区过大

- **症状**：大部分地图无风险，PvP 与掠夺形同虚设。
- **根因**：风险分层缺失或保护过度。
- **验证**：高风险区域的收益是否显著高于安全区？
- **修复**：按区域分级风险与产出；保护要有边界与代价。
