# 家园 / 基地系统 · 方法论手册（沙盒生存通用）

> 适用：任何"沙盒生存 / 经营建造"类游戏的据点、家园、农场、避难所系统。
> 内核 = 可迁移的判断框架。文中所有"本作案例 / 知名范本"仅作佐证参考，**不是设计标准**。
> 与《载具系统拆解与方法论》共用同一套"拆解→抽象方法论"骨架。

---

## 0. 一句话定位

家园不是"仓库 + 一排生产台"，它是**成长循环的物理载体**——采集 → 转化 → 变强 → 去采集更高阶。

玩家把"在外面冒险赚到的"带回这里，转化成"下次出门更强"。**这个循环一旦断了，家园就退化成容器。**

### 三角色（判断一个家园子系统是否必要）
- **生存锚点**：这里安全，冒险从这里出发
- **生产转化**：把原料变成能用的东西（武器/食物/材料/装备）
- **进度结晶**：把积累固化成分数 / 等级 / 可携带的成长
- （第四层 **身份表达**：外观/装饰/社交地位 —— **前三层成立后才是增值**，不是根基，别本末倒置）

## 1. 先答一个灵魂问题（决定后续所有设计）

**这套家园是给"想动脑的人"做的，还是给"想省心的人"做的？**

| 端 | 范式 | 爽点 | 设计要求 |
|---|---|---|---|
| 策略端 | 终末地 / 帕鲁 | 规划、优化、看生产网络跑起来 | 要**复杂** |
| 挂机端 | QQ农场 | 定期收货的期待感 | 要**省心** |

两端爽点**相反**，机制**不能混**。
**混着做 = 拿最坏一半**（策略端的复杂度 + 挂机端的离线产出）→ 两头都不爽。

安全混法：**挂机端当底，策略做可选深度**（星露谷：浇水自动化 + 种什么自己定）。

---

## 2. 定位三问（拿它评审任何子系统）

1. 它改变了玩家哪种**状态**？（生存压力 / 成长节奏 / 自我表达 / 社交地位）
2. 它制造了什么**决策**？（资源投哪 / 基地放哪 / 先解锁什么 / 造多少）
3. 产出去了**哪**、谁在**消费**、**成环**了吗？

> 三问答不顺 = 这个子系统没想清楚，先别动手。

---

## 3. 四种死法（诊断器）

- **① 管子非循环**：投入 → 产出 → 仓库，产出没回流、没改变玩家状态。白烧资源。
- **② 僵尸系统**：被上位替代，却既不退场也不转型，继续占资源、不再产出价值。
- **③ 操作粒度泄漏**：技术实现的最小单元渗漏成玩家操作的最小单元 → 逐件点击，成本 O(N×k) 而非 O(1)。
- **④ 误建模**：把 A 体系硬套进 B 体系的边界（两者核心约束不同）→ 产生不可消除的别扭。

---

## 4. 三轴标尺（判定健康度）

- **价值轴**：循环（产出回流改变状态）↔ 管子（直线到仓库）
- **时间轴**：正资产（持续产出净值）↔ 僵尸（只耗不产）
- **操作轴**：O(1) 批量自动 ↔ O(N×k) 逐件重复

> 挂机端硬指标 = **操作成本 O(1)**。

---

## 5. 制造 / 生产类系统的四条底线

1. **工作台 = 工序而非分类**：按"要经历哪几道加工"组织，不是按"成品类型"分拣。
2. **材料 = 共享中间产物**：不属于任何单个台子，跨工序共享、可流转。
3. **台子数 = 工序种类数**：不是功能数量。
4. 挂机向必须**中间件自动流转**，否则是"披挂机皮的流水线"。

---

## 6. 生产系统六法则（可迁移到种植 / 畜牧 / 制作）

1. 产出**点滴蓄积**，非一次性结算
2. 等待可以**被资源抵消**（加速=烧资源，不是傻等）
3. 生产者之间有**真实取舍**（容量略紧于需求，否则塌缩）
4. 中断只损**在途一小批**（别整批清零，免得怕切换而杀害取舍）
5. **离线续跑**（挂机端必须）
6. **资源杠杆分"时间层 + 容量层"两层**，别揉成一段（※最常踩的根因）

> 通用骨架：**时间杠杆（能跑多久）× 容量杠杆（能跑几个）× 玩家决策（选哪些）**。
> 统一参数 = 时长 / 负载 / 容量 / 产出。

---

## 7. 双轨成长轴（防归零，对齐载具方法论）

一条 **基地等级轴**（升领地/家园等级，解锁更大范围、更多建筑）+ 一条 **设施/部件等级轴**（给单个建筑/工作台堆等级），并行。

好处：
- 不会"换新基地=旧设施全废"的挫败（设施等级可留在原地迁/升）；
- 不会"一代基地吃遍天"（基地有硬瓶颈，不升设施到不了上限）。

> 检查自己家园：**只有一条成长轴 = 要么挫败，要么平淡。**

---

## 8. 放大器 + 风险阀门（跷跷板）

- **放大器面**（正和：造出生产力）→ 让玩家变强、推进度、盖更多；
- **风险阀门面**（零和/负和：产能能被掠夺、建筑能被攻击破坏）→ 让玩家为保住它而投入。

二者是跷跷板：**放大器太强 → 碾压没有对手的世界；风险阀门太强 → 没人敢盖。**

家园在此特别典型的点，是它比载具多一层"被攻击面"——不只是**产能被掠夺**（被偷走产物），还有**据点本身被攻击**（拆防御设施 / 打掉设备 / 攻基地）。这一层把"家园=安全锚点"和"家园=可被端掉的赌注"统一成同一件事：**你盖得越多越强，就越是别人的目标。**

---

## 9. 决策检查清单（上线前自检）

- [ ] 这个系统让谁来爽——想动脑的策略玩家，还是想省心的挂机玩家？**没答清就别混做。**
- [ ] 三角色(锚点/转化/结晶)它至少占了哪个？**一个都不占 = 砍。**
- [ ] 产出成环了吗，还是直线进仓库？
- [ ] 有没有僵尸系统/被上位替代的旧设施？**有就退场/转型。**
- [ ] 操作成本是不是 O(1)？（尤其挂机端）技术边界有没有泄漏到操作层？
- [ ] 产出积累挂风险阀门了吗——会被掠夺吗，据会被打吗？（多人生存）
- [ ] 成长是单轨还是双轨？防归零了吗？
- [ ] 加速是"烧资源"还是"傻等"？等待能被抵消吗？

## 附：一条可复用红线

**凡要"配置化"的 → 留 Excel；凡要"改手感/节奏"的 → 用参数曲线而非写死数字；凡要"起冲突"的 → 给惩罚留"抢救口"；凡是"放大器" → 必配一条"吃它的消耗链 + 风险阀门"。**

> 这条红线适用于本作所有"玩家可造、能放大生产力、又怕被抢被端"的系统（家园 / 载具 / 公会 / 生产线）。

## 附：可迁移的"设计陷阱"原型（教学案例，非本作标准）

从具体项目抽象出来的、换个游戏照样会踩的坑，供举一反三：

- **把「发电」误建模成「蓄水罐」**（死法④）：两者都"存东西、再消耗"看似同构；但电量是连续负载、水是离散容量，硬套后产生两段不可加速等待。→ 教训：**复用体系前先对齐核心约束，别只看表面同构。**
- **马 / 载具上位替代**（死法②）：新系统（车）做得更好，旧系统（马）不转型，留下一只"还在吃草但没人骑"的动物。→ 教训：**被替换的角色要么给新岗位，要么体面退场。**
- **逐棵作物独立对象**（死法③）：技术层把每棵作物做成独立实体，落到操作层就成了"一棵棵点"。→ 教训：**技术边界一旦泄漏到操作层，成本立刻爆炸。**
